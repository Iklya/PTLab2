# Лабораторная работа №2

## Постановка задачи

Разработать веб-приложение на Django для учета товаров, покупателей и покупок в магазине.

В рамках лабораторной работы необходимо реализовать:

- учет товаров магазина;
- учет покупателей;
- оформление покупок;
- накопительную систему скидок;
- расчет размера скидки в зависимости от общей суммы покупок покупателя;
- отображение общей суммы покупок, размера скидки, суммы скидки и итоговой суммы к оплате.

В текущей реализации используется следующая система накопительных скидок:

| Общая сумма покупок | Скидка |
| -------------------- | ------ |
| менее 5 000 руб.    | 0%     |
| от 5 000 руб.       | 3%     |
| от 10 000 руб.      | 5%     |
| от 20 000 руб.      | 10%    |

Скидка рассчитывается на основании всех покупок, связанных с конкретным покупателем.

## Краткое описание проекта

Проект представляет собой веб-приложение интернет-магазина, разработанное с использованием Django и PostgreSQL.

Основная логика приложения находится в Django-приложении `shop`.

На главной странице отображаются:

- список доступных товаров и их стоимость;
- список зарегистрированных покупателей;
- количество покупок каждого покупателя;
- общая сумма его покупок;
- текущий процент скидки;
- итоговая сумма с учетом скидки.

Также предусмотрены отдельные страницы для добавления покупателя и оформления покупки.

После оформления покупки приложение сохраняет объект `Purchase`, связанный с выбранными покупателем и товаром. На основании всех связанных покупок пересчитываются общая сумма, размер скидки и итоговая стоимость. Таким образом, накопительная скидка автоматически изменяется по мере увеличения суммы покупок.

## Реализованные модели

### Product

Модель товара содержит:

- `name` — название товара;
- `price` — цена товара.

Поле `price` хранится как `PositiveIntegerField`, поэтому цена представлена целым неотрицательным числом.

Для удобного отображения объекта реализован метод `__str__()`, возвращающий название товара.

### Customer

Модель покупателя содержит:

- `name` — имя покупателя;
- `address` — адрес покупателя.

Для покупателя реализованы методы:

- `total_spent()` — вычисляет общую сумму всех покупок;
- `discount_percent()` — определяет текущий размер накопительной скидки;
- `discount_amount()` — вычисляет сумму скидки;
- `total_with_discount()` — вычисляет итоговую сумму после применения скидки.

Связь покупателя с покупками задается через поле `related_name='purchases'`, поэтому все покупки конкретного покупателя доступны через `customer.purchases`.

### Purchase

Модель покупки содержит:

- `customer` — покупатель;
- `product` — приобретенный товар;
- `date` — дата и время создания покупки.

Поля `customer` и `product` являются внешними ключами.

Дата покупки заполняется автоматически при создании объекта за счет `auto_now_add=True`.

Для строкового представления покупки реализован метод `__str__()`, который возвращает строку вида:

```text
Ivanov Ivan: book
```

## Логика расчета скидки

Расчет скидки реализован в модели `Customer`.

Сначала определяется общая стоимость всех покупок покупателя:

```python
def total_spent(self):
    return sum(
        purchase.product.price
        for purchase in self.purchases.select_related('product').all()
    )
```

После этого выбирается размер скидки:

```python
if total >= 20000:
    return 10
if total >= 10000:
    return 5
if total >= 5000:
    return 3

return 0
```

Сумма скидки рассчитывается следующим образом:

```python
def discount_amount(self):
    return self.total_spent() * self.discount_percent() / 100
```

Итоговая стоимость:

```python
def total_with_discount(self):
    return self.total_spent() - self.discount_amount()
```

Таким образом, скидка определяется автоматически на основании накопленной суммы покупок каждого покупателя.

## Представления

В приложении используются следующие представления.

### `index`

Функция `index` получает список товаров и список покупателей и передает их в шаблон `shop/index.html`.

Главная страница доступна по адресу:

```text
/
```

### `CustomerCreate`

Класс `CustomerCreate` основан на `CreateView` и предназначен для добавления нового покупателя.

Используемые поля:

- `name`;
- `address`.

После успешного добавления выполняется перенаправление на главную страницу.

Страница доступна по адресу:

```text
/customer/add/
```

### `PurchaseCreate`

Класс `PurchaseCreate` используется для оформления покупки.

В форме выбираются:

- покупатель;
- товар.

После сохранения покупки формируется HTTP-ответ с информацией о:

- покупателе;
- общей сумме покупок;
- накопительной скидке;
- сумме скидки;
- итоговой сумме к оплате.

Страница доступна по адресу:

```text
/buy/
```
